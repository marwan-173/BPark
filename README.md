# BPark - Parking Management System

BPark is a full JavaFX-based client-server parking management system built using Java, OCSF, TCP/IP communication, and MySQL.

The system supports multiple user roles, reservation management, vehicle pickup/drop-off operations, parking history tracking, reports, and email notifications.

---

## Features

- Multi-role login system
- Subscriber management
- Parking reservation system
- Vehicle drop-off and pickup
- Parking history tracking
- Manager reports
- Real-time client-server communication
- Email notifications
- JavaFX graphical user interface
- MySQL database integration

---

## Technologies Used

- Java 17
- JavaFX 17
- MySQL
- OCSF Framework
- TCP/IP Networking
- Jakarta Mail
- Eclipse IDE
